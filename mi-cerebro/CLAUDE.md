## Notas para Claude Code
- Usa enlaces internos estilo Obsidian: [[nombre-de-pagina]].
- Para leer un PDF de más de 10 páginas usa el parámetro `pages` por tramos (máximo 20 por lectura). Si la lectura falla, avísame en lugar de adivinar el contenido; no conviertas ni copies el PDF dentro de raw/.
- Cita la página del PDF tal como aparece en su numeración impresa; si no la tiene, usa el número de página del archivo e indícalo.
- Las fechas de log.md y del campo updated: usan la fecha de hoy en formato YYYY-MM-DD.
- El proyecto usa Git (Ruta B). Los commits los hace el usuario; tú no ejecutes git add, commit, checkout, reset ni push.
- Los archivos .gitkeep solo mantienen las carpetas vacías en Git: no son páginas de la wiki.
